Put the two Moveshelf screenshots in this folder, then run:

    python docs/add_screenshots.py

Exactly these two file names (.png or .jpg both work):

  profile-menu.png
      The top of a Moveshelf page with the profile menu open, so SETTINGS is
      visible. Include the blue Moveshelf bar AND the grey browser bar above it,
      because the whole point is showing which of the two round buttons to click.

  api-keys.png
      The User settings page scrolled down to the API Keys panel, showing the
      "Application ID*" box and the "Generate API Key" button.

DO NOT screenshot a generated key.
The long string Moveshelf shows after you click "Generate API Key" is a live
password. Take this screenshot BEFORE generating one, or after the value has
gone from the screen.
