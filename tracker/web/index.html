Set up your API key

Report Tracker needs its own Moveshelf API key. This takes about a minute.

  1. Log in to Moveshelf, click your picture at the top right, then User settings.
  2. Scroll down to API Keys.
  3. In the Application ID box type ReportTracker, then click Generate API Key.
  4. Save the file Moveshelf gives you into this folder, named mvshlf-api-key.json:
  5. Click Refresh above.

Use a dedicated Application ID rather than an existing key, so this one can be revoked on its own later without breaking anything else. The key is a password: it is yours alone, and it should never be emailed, shared, or put on a network drive. You can revoke it at any time from the same screen, with no IT ticket.

Choose your site
